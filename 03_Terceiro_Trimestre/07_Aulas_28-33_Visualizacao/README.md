# Aulas 28-33: Visualização de Dados (Terminal)

**Objetivo:** Transformar números chatos em imagens fáceis de entender.

## Conteúdo
1.  **Gráficos de Barra:** Usando caracteres repetidos (`*` * 10).
2.  **Relatórios Formatados:** Alinhando texto com `f-strings`.
3.  **Histórias com Dados:** Contar o que os números significam.

## Estrutura dos Arquivos
-   `Aula-07-Visualizacao.md`: Como desenhar com texto.
-   `src/`: Exemplos de gráficos de vendas e notas.
-   `Exercicios_07_Visualizacao.md`: Prática de desenho de dados.
