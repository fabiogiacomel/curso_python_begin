# Aulas 10-12: Retorno de Valores e Escopo

**Objetivo:** Fazer a função trabalhar em equipe com o resto do programa, devolvendo resultados.

## Conteúdo
1.  **O comando `return`:** Transformando a função em uma fábrica de dados.
2.  **Diferença Print x Return:** O erro número 1 dos iniciantes.
3.  **Escopo (Local vs Global):** Onde as variáveis vivem (e morrem).

## Estrutura dos Arquivos
-   `Aula-03-Return-Escopo.md`: Entendendo o fluxo de dados.
-   `src/`: Exemplos de cálculos e correção de escopo.
-   `Exercicios_03_Return.md`: Prática de funções que devolvem valores.
