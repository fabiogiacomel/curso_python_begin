# Aulas 04-09: Funções com Parâmetros

**Objetivo:** Criar funções inteligentes que se adaptam aos dados.

## Conteúdo
1.  **Parâmetros:** O que vai dentro do `()`.
2.  **Argumentos:** Os dados que enviamos.
3.  **Múltiplos Parâmetros:** Enviando mais de uma coisa.

## Estrutura dos Arquivos
-   `Aula-02-Parametros.md`: Enviando informações.
-   `src/`: Exemplos de calculadora e saudação personalizada.
-   `Exercicios_02_Parametros.md`: Prática de envio de dados.
