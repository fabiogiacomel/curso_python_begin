# Projeto Final: Sistema de Gestão Escolar

**Objetivo:** Criar um sistema completo para gerenciar notas de alunos.
**Integração:** Funções, Listas, Loop, Condicionais, Matemática e Visualização.

## Funcionalidades
1.  **Menu Principal:** (Cadastrar, Listar, Relatório, Sair).
2.  **Cadastro:** Nome do aluno e 3 notas.
3.  **Cálculo:** Função que calcula a média e diz se foi Aprovado (Média >= 7).
4.  **Relatório Visual:** Mostrar um gráfico de barras com as médias da turma.

## Estrutura Sugerida
*   `main.py`: O loop principal e o menu.
*   `funcoes.py`: As funções de cálculo e desenho (opcional, pode ser tudo em um arquivo se preferir).

## Critérios de Destaque
*   Validar se as notas estão entre 0 e 10.
*   Permitir excluir um aluno.
*   Mostrar a maior e a menor média da turma.
