# Aulas 16-21: Manipulação de Strings (Limpeza)

**Objetivo:** Arrumar textose limpar sujeira (espaços, letras erradas) antes de usar.

## Conteúdo
1.  **Caixa Alta/Baixa:** Padronizar nomes (`upper`, `lower`).
2.  **Limpeza:** Tirar espaços inúteis (`strip`).
3.  **Substituição:** Trocar palavras (`replace`).
4.  **Fatiamento:** Pegar pedaços do texto (Igual a listas!).

## Estrutura dos Arquivos
-   `Aula-05-Strings.md`: Comandos de texto.
-   `src/`: Exemplos de correção de cadastro.
-   `Exercicios_05_Strings.md`: Prática de formatação.
