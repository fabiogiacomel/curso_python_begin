# Aulas 01-09: Estruturas de Repetição (While)

**Objetivo:** Fazer o computador trabalhar para nós, repetindo tarefas chatas milhares de vezes.

## Conteúdo
1.  **O Conceito de Loop:** O que é iteração (repetição).
2.  **While (Enquanto):** Repete *enquanto* uma condição for verdadeira.
3.  **Loop Infinito:** O perigo de não ter fim (e como parar O Computador).
4.  **Acumuladores:** Somar valores dentro de um loop.
