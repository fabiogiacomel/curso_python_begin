# Aulas 16-18: Interrompendo Laços (Break e Continue)

**Objetivo:** Ter controle total sobre quando um loop para ou pula uma etapa.

## Conteúdo
1.  **O comando `break`:** Para o loop IMEDIATAMENTE (sai do ciclo).
2.  **O comando `continue`:** Pula APENAS a volta atual (vai para a próxima iteração).
3.  **Loop Infinito Controlado:** Usar `while True` com `break`.

## Estrutura dos Arquivos
-   `Aula-04-Break-Continue.md`: A diferença entre parar e pular.
-   `src/`: Exemplos de login e pular números indesejados.
-   `Exercicios_03_Break.md`: Prática de controle de fluxo.
