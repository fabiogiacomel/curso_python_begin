# Aulas 22-27: Métodos de Listas

**Objetivo:** Alterar as listas depois de criadas. Mexer no conteúdo.

## Conteúdo
1.  **Adicionar:** `append()` para colocar no final.
2.  **Remover:** `remove()` (pelo valor) e `pop()` (pela posição).
3.  **Organizar:** `sort()` para ordenar A-Z ou 0-9.
4.  **Contar:** `count()` para saber quantos tem.

## Estrutura dos Arquivos
-   `Aula-06-Metodos-Listas.md`: Comandos para manipular listas.
-   `src/`: Exemplos de fila e organização.
-   `Exercicios_05_Metodos.md`: Prática de manipulação.
