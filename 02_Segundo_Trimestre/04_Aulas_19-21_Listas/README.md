# Aulas 19-21: Introdução às Listas (Coleções)

**Objetivo:** Guardar muitos valores em uma única variável.

## Conteúdo
1.  **O que é uma Lista:** Uma "gaveta" com várias divisórias.
2.  **Criação:** Usando colchetes `[]`.
3.  **Acesso (Indexação):** Posição 0, 1, 2...
4.  **Fatiamento (Slicing):** Pegar um pedaço da lista.

## Estrutura dos Arquivos
-   `Aula-05-Intro-Listas.md`: Como criar e acessar.
-   `src/`: Exemplos de listas de compras e notas.
-   `Exercicios_04_Listas.md`: Prática de indexação.
