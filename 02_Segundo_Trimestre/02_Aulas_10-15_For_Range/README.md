# Aulas 10-15: O Laço For e Range

**Objetivo:** Repetir um número exato de vezes, sem precisar contar manualmente.

## Conteúdo
1.  **O Laço For (Para):** Ideal quando sabemos quantas vezes queremos repetir.
2.  **A Função `range()`:** Um gerador de sequências numéricas.
3.  **Diferença While vs For:** Quando usar cada um.

## Estrutura dos Arquivos
-   `Aula-03-For-Range.md`: Como usar o for para contar.
-   `src/`: Exemplos de repetição controlada.
-   `Exercicios_02_For.md`: Prática de loops definidos.
