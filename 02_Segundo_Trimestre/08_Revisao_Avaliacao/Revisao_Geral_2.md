# Revisão do 2º Trimestre

**Tópicos para Estudar:**
1.  **While:** Loop com condição (enquanto for verdade).
2.  **For + Range:** Loop com contador (sabe quantas vezes).
3.  **For + Lista:** Loop para cada item (iterar).
4.  **Listas:**
    *   Criar: `[]`
    *   Acessar: `lista[0]`
    *   Adicionar: `append()`
    *   Remover: `pop()` ou `remove()`
    *   Tamanho: `len()`

---

## Lista de Exercícios Rápidos

1.  Faça um loop que conte de 10 até 0 (Foguete).
2.  Crie uma lista de compras com 3 itens.
3.  Adicione "Chocolate" nessa lista.
4.  Imprima o **segundo** item da lista.
5.  Faça um loop que imprima "Eu gosto de [item]" para cada coisa na lista.
