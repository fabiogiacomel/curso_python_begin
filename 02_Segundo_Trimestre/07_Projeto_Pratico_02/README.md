# Projeto Prático 02: Gerenciador de Tarefas (ToDo)

**Objetivo:** Criar um aplicativo útil para organizar a vida.
**Conceitos:** Menu Infinito (`while`), Listas (`append`, `pop`) e Visualização (`for`).

## Funcionalidades Obrigatórias
1.  **Menu Principal:** O programa não pode parar sozinho.
2.  **Adicionar Tarefa:** O usuário digita e ela vai para a lista.
3.  **Listar Tarefas:** Mostrar todas as tarefas numeradas (1, 2, 3...).
4.  **Concluir/Remover:** O usuário escolhe o número da tarefa para apagar.

## Critérios de Avaliação
1.  **Usabilidade:** O menu é fácil de entender?
2.  **Robustez:** Se eu tentar apagar uma tarefa que não existe, o programa quebra? (Tente usar `if` para evitar erros).
3.  **Código Limpo:** Variáveis com nomes em português e claros.
