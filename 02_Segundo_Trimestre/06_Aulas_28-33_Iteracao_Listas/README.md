# Aulas 28-33: Iteração em Listas (For Each)

**Objetivo:** Ler todos os itens de uma lista, um por um, sem erros.

## Conteúdo
1.  **For In:** O comando mágico que percorre a lista.
2.  **Acumuladores:** Somar ou juntar coisas da lista.
3.  **Filtragem:** Usar `if` dentro do `for` para pegar só o que queremos.
