# Aulas 01-03: Introdução à Lógica de Programação

**Objetivo:** Compreender o que são instruções passo-a-passo (algoritmos) e como o computador executa comandos sequenciais.

## Conteúdo
1.  **Conceito de Algoritmo:** Instruções claras e finitas para resolver um problema.
2.  **Pensamento Computacional:** Decomposição (quebrar problemas) e Abstração (focar no importante).
3.  **Sequenciamento:** A ordem dos comandos importa.

## Estrutura dos Arquivos
-   `Aula-01-Algoritmos.md`: Explicação teórica com exemplos práticos.
-   `Exercicios_01.md`: Lista de exercícios graduais (Método Kumon).
-   `src/`: Contém os códigos de exemplo (scripts Python simples).

## Como Estudar
1.  Leia o `Aula-01-Algoritmos.md`.
2.  Abra e execute os exemplos da pasta `src/` no seu editor ou terminal.
3.  Faça os exercícios do `Exercicios_01.md` na ordem proposta.
-   **Série A:** Apenas copie e veja funcionar.
-   **Série B:** Modifique valores.
-   **Série C:** Crie seus próprios algoritmos.
