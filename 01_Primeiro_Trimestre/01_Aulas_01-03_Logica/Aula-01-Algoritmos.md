# Aula 01: Algoritmos e Sequência

**Objetivo:** Entender que um programa é uma receita de bolo: uma lista de instruções que o computador segue uma por uma.

---

## Exemplo 1: A Receita de Bolo (Sequência)

Imagine que você está ensinando um robô a fazer um bolo. Você não pode dizer apenas "faça um bolo". Você precisa dar instruções exatas.

### Veja o Código (Exemplo Python)
Abra o arquivo `src/exemplo_01_receita.py`:

```python
# Instruções para fazer um bolo simples
print("1. Pegar os ovos")
print("2. Bater os ovos")
print("3. Adicionar farinha")
print("4. Colocar no forno")
print("5. Esperar 30 minutos")
print("6. Bolo pronto!")
```

### Análise (Método Kumon)
1.  **Observe:** O comando `print(...)` mostra texto na tela.
2.  **Observe:** As instruções aparecem na ordem em que foram escritas (de cima para baixo).
3.  **Reflexão:** Se trocarmos a ordem (colocar no forno antes de adicionar farinha), o bolo vai dar certo? Não. A **sequência** é fundamental.

## Exemplo 2: Desenho Geométrico (Decomposição)

Para desenhar um quadrado, o robô precisa de passos menores.
Decompor é quebrar uma tarefa grande em tarefas menores.

### Tarefa: Desenhar um Quadrado
1.  Andar para frente
2.  Virar 90 graus
3.  Andar para frente
4.  Virar 90 graus
5.  Andar para frente
6.  Virar 90 graus
7.  Andar para frente

Isso se repete! Se o computador sabe fazer "Andar" e "Virar", ele consegue fazer um quadrado.
