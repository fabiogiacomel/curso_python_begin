# Aulas 16-18: Operadores Relacionais e Lógicos

**Objetivo:** Ensinar o computador a tomar decisões baseadas em Sim ou Não (True/False).

## Conteúdo
1.  **Operadores Relacionais:** Comparam dois valores (Maior, Menor, Igual).
2.  **Operadores Lógicos:** Combinam comparações (E, OU, NÃO).
3.  **Tabela Verdade:** A lógica por trás das combinações.
