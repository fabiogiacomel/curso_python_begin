# Aulas 25-30: Condicionais Aninhadas e Elif

**Objetivo:** Tomar decisões quando existem mais de duas opções (não é só "Sim ou Não").

## Conteúdo
1.  **O comando `elif`:** Abreviação de "Else If" (Senão Se). Para testar várias coisas em sequência.
2.  **Aninhamento:** Colocar um `if` dentro de outro `if`. (Decisões dentro de decisões).
3.  **Lógica Complexa:** Resolver problemas que exigem múltiplas verificações.

## Estrutura dos Arquivos
-   `Aula-16-Elif.md`: Escolhendo entre A, B ou C.
-   `Aula-17-Aninhamento.md`: Um `if` dentro do outro.
-   `src/`: Exemplos de categorias e login avançado.
-   `Exercicios_16.md`: Prática de lógica ramificada.
