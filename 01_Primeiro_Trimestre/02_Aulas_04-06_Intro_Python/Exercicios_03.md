## Série A: Reprodução
*Objetivo: Escrever sem erros de digitação.*

**A1.** Crie um arquivo `meu_primeiro_codigo.py`.
**A2.** Digite e execute:
```python
print("Python é legal")
print("Estou aprendendo muito")
# print("Isso aqui não vai aparecer")
```

## Série C: Criação
*Objetivo: Criar do zero.*

**C1.** Crie um programa que faça um "desenho" simples usando apenas números e `print`.
Exemplo da "Escada":
```python
print("1")
print("12")
print("123")
print("1234")
```
Seu desafio: Faça uma **Pirâmide** ou um **Quadrado** de asteriscos `*`.
