# Projeto Prático 01: Consolidando o Conhecimento

**Objetivo:** Criar um programa completo usando tudo o que aprendemos até agora.
**Tempo Estimado:** 6 aulas.

## Opções de Projeto
Você deve escolher **UM** dos projetos abaixo para desenvolver:

### Opção A: O Quiz (Show do Milhão)
Um jogo de perguntas e respostas.
*   Deve ter pelo menos 3 perguntas.
*   Deve contar pontos (Score).
*   Deve mostrar uma mensagem final dependendo da pontuação.

### Opção B: A Super Calculadora
Uma ferramenta que realiza cálculos baseados na escolha do usuário.
*   Deve ter um menu (Soma, Sub, Mult, Div, Potência).
*   Deve tratar divisão por zero (não deixar quebrar).
*   Deve perguntar se o usuário quer fazer outra conta (Opcional, se souber usar `while`, senão faz só uma vez).

## Critérios de Avaliação
1.  **Funcionalidade:** O código roda sem erros?
2.  **Legibilidade:** Variáveis têm bons nomes? Tem comentários?
3.  **Interface:** As mensagens para o usuário são claras e bonitas (f-strings)?
4.  **Criatividade:** As perguntas/mensagens são originais?

## Entregáveis
*   Arquivo `.py` finalizado.
*   Apresentação rápida para a turma (rodar e mostrar funcionando).
