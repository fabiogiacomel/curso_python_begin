# Aulas 19-24: Estruturas Condicionais (if/else)

**Objetivo:** Ensinar o computador a tomar decisões sozinho. "Se isso acontecer, faça aquilo. Senão, faça outra coisa."

## Conteúdo
1.  **Condicional Simples (`if`):** Executa um bloco de código APENAS SE a condição for verdadeira.
2.  **Indentação:** A regra de ouro do Python (o espaço no começo da linha).
3.  **Condicional Composta (`if/else`):** O "Plano B" do código.

## Estrutura dos Arquivos
-   `Aula-14-Condicional-Simples.md`: O comando `if` e a indentação.
-   `Aula-15-Condicional-Composta.md`: O comando `else`.
-   `src/`: Exemplos de verificação de idade e senhas.
-   `Exercicios_14.md`: Prática de decisão.
