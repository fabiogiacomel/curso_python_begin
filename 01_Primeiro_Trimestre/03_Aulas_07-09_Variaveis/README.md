# Aulas 07-09: Variáveis e Tipos Primitivos

**Objetivo:** Aprender como guardar informações na memória do computador.

## Conteúdo
1.  **Variáveis:** Etiquetas para guardar dados.
2.  **Tipos Primitivos:** As 4 formas básicas de informação.
    -   `str` (Texto)
    -   `int` (Número Inteiro)
    -   `float` (Número Decimal)
    -   `bool` (Verdadeiro ou Falso)
3.  **Tipagem Dinâmica:** O Python descobre o tipo sozinho.

## Estrutura dos Arquivos
-   `Aula-05-Variaveis.md`: O conceito de caixas/etiquetas.
-   `Aula-06-Tipos-Primitivos.md`: Diferença entre texto e número.
-   `src/`: Exemplos práticos para rodar.
-   `Exercicios_05.md`: Prática Kumon de fixação.
