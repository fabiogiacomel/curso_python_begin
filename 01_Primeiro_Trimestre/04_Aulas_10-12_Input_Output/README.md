# Aulas 10-12: Entrada e Saída de Dados

**Objetivo:** Interagir com o usuário, perguntando coisas e respondendo de forma personalizada.

## Conteúdo
1.  **Entrada (`input`):** Como receber dados do teclado.
2.  **Conversão de Tipos (`int()`, `float()`):** Transformar texto em número.
3.  **Saída Formatada (`f-strings`):** Misturar texto e variáveis de forma elegante.

## Estrutura dos Arquivos
-   `Aula-07-Input.md`: O comando para ler o teclado.
-   `Aula-08-Formatacao.md`: Textos bonitos com variáveis.
-   `src/`: Exemplos de interação.
-   `Exercicios_07.md`: Prática de diálogo com o computador.
